# Alexandria
This repository hosts the source code for Alexandria.

## Usage as a dependency
When using Maven, you need to add the following repository:
```
<repository>
    <id>jitpack.io</id>
    <url>https://jitpack.io</url>
</repository>
```
And then the following dependency (replace `version` with the latest version):
```
<dependency>
    <groupId>com.github.ManosSef</groupId>
    <artifactId>Alexandria</artifactId>
    <version>version</version>
</dependency>
```
When using Gradle, you need to add the following repository:
```
maven { url 'https://jitpack.io' }
```
And then the following dependency (replace `version` with the latest version):
```
implementation 'com.github.ManosSef:Alexandria:version'
```
